Base de données

La base de données est composée de 8 tables interconnectées permettant de gérer les utilisateurs, les compétences, les disponibilités, les offres de mentorat, les matchings et la messagerie.

Table Rôle
utilisateur Stocke les informations de chaque étudiant
competence Liste des matières et compétences disponibles
utilisateur_competence Relie les utilisateurs à leurs compétences et lacunes
disponibilite Créneaux horaires de chaque utilisateur
offre_mentorat Offres et demandes de mentorat publiées
matching Paires mentor-mentoré générées par l'algorithme
conversation Conversations entre utilisateurs
message Messages échangés dans les conversations

4. Instructions de Déploiement

Prérequis

  • Python 3.x installé
  • MySQL ou PostgreSQL installé
  • Git installé

Étapes d'installation

# 1. Cloner le dépôt
git clone https://github.com/[compte]/PIL1_2526_50.git

# 2. Aller dans le dossier backend
cd PIL1_2526_50/backend

# 3. Installer les dépendances
pip install -r requirements.txt

# 4. Créer la base de données
mysql -u root -p < ../database/mentorlink.sql

# 5. Lancer l'application
python app.py

5. Manuel d'Utilisation

Inscription

Rendez-vous sur la page d'accueil et cliquez sur "S'inscrire". Remplissez le formulaire avec vos informations personnelles (nom, prénom, email, téléphone, mot de passe, filière et niveau).

Connexion

Entrez votre adresse email ou numéro de téléphone ainsi que votre mot de passe sur la page de connexion.

Compléter son profil

Après connexion, accédez à votre profil pour ajouter vos compétences maîtrisées, vos lacunes et vos disponibilités horaires.

Publier une offre ou demande de mentorat

Cliquez sur "Nouvelle offre" ou "Nouvelle demande", choisissez la matière concernée, le format et vos disponibilités.

Trouver un mentor ou mentoré

Accédez à la section "Matching" pour voir les suggestions générées automatiquement selon vos compétences et disponibilités.

Messagerie

Depuis la section "Messages", vous pouvez envoyer et recevoir des messages avec vos mentors ou mentorés.
