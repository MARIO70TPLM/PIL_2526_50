Base de données

La base de données mentorlink est gérée avec MySQL. Elle est composée de 11 tables interconnectées couvrant la gestion des utilisateurs, des offres de mentorat, du matching et de la messagerie.

Table Rôle
UtilisateurInformations personnelles de chaque étudiant (nom, email, filière, niveau, mot de passe hashé...)
OffreOffres et demandes de mentorat publiées par les utilisateurs
MatiereListe des matières et compétences disponibles
DisponibiliteCréneaux horaires généraux (matin / midi / après-midi par jour)
FormatFormat de rencontre : en ligne ou présentiel
Offre_MatiereTable de liaison entre Offre et Matiere (relation N-N)
Offre_DisponibiliteTable de liaison entre Offre et Disponibilite (relation N-N)
Offre_FormatTable de liaison entre Offre et Format (relation N-N)
Score_matchingScores de compatibilité calculés entre paires d'offres mentor/mentoré
ConversationConversations entre deux utilisateurs matchés
MessageMessages échangés au sein des conversations

Architecture logicielle

L'application suit une architecture client-serveur. Le frontend (HTML/CSS/JavaScript) communique avec le backend via des requêtes HTTP. Le backend Python Flask reçoit ces requêtes, interroge la base MySQL, et retourne les données en JSON. Les mots de passe sont hashés avec la bibliothèque werkzeug.security.

4. Instructions de Déploiement

Prérequis

  • Python 3.x installé
  • MySQL installé et en cours d'exécution
  • Git installé
  • pip installé

Étapes d'installation

# 1. Cloner le dépôt
git clone https://github.com/MARIO70TPLM/PIL_2526_50.git
cd PIL_2526_50

# 2. Installer les dépendances Python
pip install flask flask-mysqldb werkzeug --break-system-packages

# 3. Créer la base de données MySQL
sudo mysql -u root
CREATE DATABASE mentorlink;
exit

# 4. Importer la structure de la base de données
sudo mysql -u root mentorlink < backend/mentorlink.sql

# 5. Configurer la connexion dans backend/app.py
# Modifier MYSQL_PASSWORD avec votre mot de passe root MySQL

# 6. Lancer le serveur Flask
cd backend
python3 app.py

Accéder à l'application

Une fois le serveur lancé, ouvrez votre navigateur et rendez-vous sur : http://127.0.0.1:5000

5. Manuel d'Utilisation

Inscription

Rendez-vous sur la page d'accueil et cliquez sur "S'inscrire". Remplissez le formulaire avec vos informations personnelles (nom, prénom, email, numéro de téléphone, mot de passe, filière et niveau d'études), puis cliquez sur "Créer mon compte".

Connexion

Entrez votre adresse email et votre mot de passe sur la page de connexion, puis cliquez sur "Se connecter".

Compléter son profil

Après connexion, accédez à votre profil pour renseigner vos compétences maîtrisées, vos matières où vous avez besoin d'aide, et vos disponibilités horaires.

Publier une offre ou demande de mentorat

Rendez-vous dans la section "Matching", remplissez le formulaire de publication (matières concernées, disponibilités, format souhaité) et cliquez sur "Publier".

Trouver un mentor ou mentoré

La section "Matching" affiche automatiquement les profils compatibles avec le vôtre, classés par score de compatibilité. Vous y trouvez les matières en commun, les disponibilités communes et le score de compatibilité.

Messagerie

Une fois un match établi, le bouton "Contacter" devient disponible sur le profil du mentor ou mentoré. Depuis la section "Messages", vous pouvez envoyer et recevoir des messages et consulter l'historique de vos conversations.
